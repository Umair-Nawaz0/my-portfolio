## 🛠️ Tech Stack & Architecture

- **Framework**: [Next.js 16 (Turbopack)](https://nextjs.org/)

- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with glassmorphism and animated glow shaders
- **Animation**: [Motion](https://motion.dev/)
- **Deployment**: [Vercel](https://vercel.com/) with automatic edge optimization
