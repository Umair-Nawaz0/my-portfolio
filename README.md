## 🛠️ Stack & Optimization

- **Framework**: Next.js 16 (Turbopack) & React 19
- **Styling**: Tailwind CSS v4 with dark/light mode
- **Assets**: Optimized WebP compression (<35KB total payload)
- **Architecture**: Lightweight single-page application with static generation and sub-second load times
- **Deployment**: Automatic CI/CD deployment on [Vercel](https://vercel.com/)
