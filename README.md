## 🛠️ Tech Stack & Architecture

- **Framework**: [Next.js 16 (Turbopack)](https://nextjs.org/)
- **UI & Components**: [React 19](https://react.dev/), [Base UI](https://base-ui.com/), [Lucide Icons](https://lucide.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with custom glassmorphism and animated glow shaders
- **Animation**: [Motion](https://motion.dev/) (Framer Motion)
- **Language**: [TypeScript](https://www.typescriptlang.org/) with strict type validation
- **Routing**: Next.js App Router with SSG (`generateStaticParams`) for instant sub-page navigation

## 💻 Local Development Setup

### Prerequisites
- Node.js `20.x` or `22.x`
- npm

### Installation & Execution

```bash
# 1. Clone the repository
git clone https://github.com/Umair-Nawaz0/my-portfolio.git
cd my-portfolio

# 2. Install dependencies
npm install

# 3. Launch development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
